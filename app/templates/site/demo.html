실습 안내

이 사이트는 보안 진단 실습용으로 만든 가상 회사 환경이다. 아래는 진단 대상과 시작 방법이다.

실제 개인정보를 입력하지 않는다. 시드로 만든 가상 인물 10명만 쓴다.

인증 화면은 직접 열 수 없다

인증 화면은 위탁사(가상자산 거래소) 서버가 서명된 인증 요청을 보내야 열린다. 주소를 직접 입력해 들어갈 수 없고, 발급된 1회용 주소는 10분 안에 한 번만 쓸 수 있다. 실습에서는 가짜 거래소 스크립트로 요청을 보내 주소를 받는다.

  • tools/fake_exchange.py request — 인증 요청을 보내고 인증 화면 주소를 받는다.
  • tools/fake_exchange.py serve — 결과 통보를 받아 서명을 검증하고 출력한다.
  • tools/demo_reset.sh — 환경을 처음 상태로 되돌린다.
