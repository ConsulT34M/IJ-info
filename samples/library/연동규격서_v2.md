# 본인확인 연동 규격 v2 (요약본)

주식회사 인증정보평가 · 실습용 가상 문서입니다.

## 요청 서명

    X-Api-Key    발급받은 API Key
    X-Timestamp  유닉스 초 문자열 (현재 시각 ±300초)
    X-Signature  hex(HMAC-SHA256(key=HMAC Secret, msg=X-Timestamp 바이트 + 원본 본문 바이트))

구분자 없이 이어 붙이며, 소문자 hex로 보냅니다. 본문 없는 GET은 빈 바이트에 서명합니다.

## 연동 방식

- REDIRECT: 인증 화면을 인증정보평가가 띄웁니다. 기본값입니다.
- DIRECT: 인증 화면을 위탁사가 만들고, 서버 간 API로 제출합니다.

자세한 내용은 담당 채널로 안내해 드립니다. API Key와 비밀키는 공개 채널로 주고받지 않습니다.
